# Changelog

All notable changes to this project are recorded here. The format follows the spirit of [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [1.0.0] - 2026-11-27

### Added

- Initial public community-ready playbook for modernizing existing .NET 10 Web APIs.
- Nine strategy and implementation guides.
- Eight reusable AI prompts covering preflight, assessment, planning, skeleton, vertical slices, dependency modernization, final validation and independent review.
- Reusable planning, parity, risk and progress templates.
- Community contribution, feedback, security and governance documentation.
- GitHub issue forms, pull request template, Markdown quality workflow and Dependabot configuration.
