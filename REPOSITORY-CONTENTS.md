# Repository contents

This file lists the principal parts of the project.

## Core files

- `README.md` — landing page and recommended adoption path.
- `LICENSE` — MIT License.
- `CONTRIBUTING.md` — contribution process.
- `CODE_OF_CONDUCT.md` — community expectations.
- `SECURITY.md` — private vulnerability reporting guidance.
- `SUPPORT.md` — support channels and expectations.
- `CHANGELOG.md` — release history.
- `CITATION.cff` — citation metadata.
- `.github/` — issue forms, pull request template, Dependabot and Markdown quality workflow.
- `guides/` — modernization guides.
- `prompts/` — reusable AI-agent prompts.
- `templates/` — planning and validation templates.
- `docs/` — community, feedback, roadmap and repository governance documentation.
