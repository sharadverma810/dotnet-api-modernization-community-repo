# Support

This is a community-maintained playbook, not a commercial support service. No service-level agreement or guaranteed response time is provided.

- **How-to questions:** use GitHub Discussions if enabled.
- **Possible documentation defect:** open an Issue using the appropriate template.
- **New idea or improvement:** open an enhancement Issue or start a Discussion.
- **Security concern:** follow [SECURITY.md](SECURITY.md); do not post it publicly.
- **Conduct concern:** follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) and contact maintainers privately.

Before asking, check the [FAQ](docs/FAQ.md), existing Issues and the relevant guide/prompt. Share only sanitized, synthetic examples. Do not upload employer/client source code or confidential project information.
